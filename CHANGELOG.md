## [0.2.0] - 2026-09-26

### Added
- Initial public release of `heka2abf` on GitHub.
- Self-contained ABF2 writer (no external ABF write dependency — pyABF only
  supports writing ABF1).
- Multi-channel interleave storage: HEKA ADC channels within a single series
  are stored as ABF2 channels in one file.
- Per-channel scale factors with int16 storage (matches real Clampfit files).
- Unit normalization: V → mV, A → pA by default (configurable in
  `heka2abf/convert.py` `_normalize_unit()`).
- Acquisition mode auto-detection: single-sweep series → gap-free (mode 3),
  multi-sweep → episodic (mode 5).
- Variable-length sweep handling via ABF2 SIC synch array (last-sweep-was-cut
  recordings round-trip cleanly).
- Per-sweep start time (`HEKA SweepRecord.Time`) written to SIC for
  PatchMaster-consistent absolute sweep timing in Clampfit.
- Optional `--one-file-per-channel` to split multi-channel series.
- Tkinter GUI (`heka2abf/gui.py`) for non-CLI users: add files / folders,
  output location, mode selection, real-time log.
- CLI (`heka2abf.cli`): `--inspect` for structure dump, full conversion.
- Windows installer scripts (`install.bat` / `run_gui.bat` /
  `run_gui_console.bat`) for non-Python-expert colleagues.
- Synthetic-data tests (`tests/test_abf2writer.py`) validating channel
  count / sweep count / sample rate / units / names / waveform.
- Reference-file test that reads a real Clampfit ABF2 (`reference/model_vc_ramp.abf`)
  and verifies round-trip physical values within int16 quantization.
- Real-HEKA-`.dat` end-to-end test (`tests/test_real_dat.py`) with zero-error
  round-trip on real data (file locations parameterized; skipped on CI).

### Known limitations
- HEKA files recorded with PatchMaster's optional lossy compression (min/max
  pairs) are read back as raw min/max values; standard patch-clamp recordings
  are uncompressed.
- Two SSCH-string header offset fields (bytes 12 / 16 within the entry) are
  generated by the heuristic of real Clampfit files; pyABF does not read
  them and Clampfit ignores them in practice.

### Vendored third-party
- `third_party/heka_reader.py` — Luke Campagnola's HEKA `.dat` parser
  (https://github.com/campagnola/heka_reader). Vendored as a single-file
  module because the upstream repository carries no PyPI release and no
  license file. `install.bat` / `install.sh` copy it into the active
  environment's `site-packages`.
