# heka2abf v0.2.0 (2026-09-26)

Initial public release of **heka2abf** — a Python tool (CLI + tkinter GUI) that
converts HEKA PatchMaster `.dat` files to **ABF2** (Axon Binary Format 2),
readable by Molecular Devices Clampfit and [swharden/pyABF](https://github.com/swharden/pyABF).

## Highlights

* **Self-contained ABF2 writer** — no external ABF write dependency (pyABF
  only supports writing ABF1, which loses information). The writer mirrors
  real Clampfit file layout: FB file section, PIL / ADC / STR / DATA / SIC
  sections, SSCH string area; **int16 + per-channel scale factors** storage
  (matching pClamp-native files).
* **Multi-channel interleave storage** — HEKA ADC channels within a single
  series are stored as ABF2 channels in one file. Use `--one-file-per-channel`
  to split per ADC.
* **Unit normalization** — V → mV, A → pA by default (signal values scaled
  in lockstep); configurable in `heka2abf/convert.py`.
* **Acquisition mode auto** — multi-sweep → episodic (mode 5), single-sweep /
  continuous → gap-free (mode 3). Override with `--mode episodic` /
  `--mode gapfree`.
* **Variable-length sweeps** — HEKA's "last-sweep-cut-short" pattern
  (interrupted recordings) is handled natively via the ABF2 SIC synch array;
  Clampfit and pyABF read each sweep correctly.
* **Sweep start times** — HEKA `SweepRecord.Time` written to SIC so absolute
  sweep timing in Clampfit matches PatchMaster.
* **Tkinter GUI** — add files / folders, output location, mode, real-time
  log. No third-party GUI dependency.
* **CLI** — `heka2abf data.dat -o out/`, plus `--inspect` for structure dump.

## Installation

### From source (development)

```bash
git clone https://github.com/ww-001/heka2abf.git
cd heka2abf
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
pip install numpy pyabf
cp third_party/heka_reader.py .venv/lib/python*/site-packages/
# Windows (PowerShell)
.\.venv\Scripts\pip install numpy pyabf
copy /y third_party\heka_reader.py .venv\Lib\site-packages\heka_reader.py
```

Or use the one-click scripts:

| OS | Install | Launch GUI |
|---|---|---|
| Windows | `install.bat` | `run_gui.bat` |
| Linux / macOS | `./install.sh` | `./run_gui.sh` |

## Verification

* `tests/test_abf2writer.py` — synthetic data round-trip + a real Clampfit
  ABF2 file (`reference/model_vc_ramp.abf`, 50 sweeps) round-trip within
  int16 quantization.
* `tests/test_real_dat.py` — real HEKA `.dat` files end-to-end: variable-length
  sweeps, two-channel IV, 30+ sweep CC injection, membrane tests. **Maximum
  absolute error = 0** on every sample.
* CI: GitHub Actions runs `test_abf2writer.py` on Python 3.9–3.12 across
  Ubuntu on every push.

## Known Limitations

* HEKA files written with PatchMaster's optional lossy compression (min/max
  pairs) are read back as raw min/max values. Standard patch-clamp
  recordings are uncompressed, so this doesn't affect typical use.
* Two SSCH-string header offset fields (bytes 12/16 within the entry) are
  generated by the heuristic of real Clampfit files; pyABF doesn't read
  them and Clampfit's string window ignores them in practice.

## Vendored Third-Party

`third_party/heka_reader.py` is Luke Campagnola's HEKA `.dat` parser
(https://github.com/campagnola/heka_reader). It is vendored as a single-file
module because the upstream repository carries no PyPI release and no
license file. `install.bat` / `install.sh` copy it into the active
environment's `site-packages`.
